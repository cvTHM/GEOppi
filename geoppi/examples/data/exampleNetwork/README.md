# README for exampleNetwork data

- gpkg files are preconditions for creation of pandapipes network from geo-referenced data
  - buildings : heat consumers
  - streetsRaw : street lines defining pipe routing
  - valves : points defining valve locations
  - producers2 : polygons denoting locations of heat producers
  - dgm : digital height model containing geospatial height information

- exampleNetwork_ppi.p : pickle file for entire pandapipes network including heat consumers, heat production sites, pipes, junctions, valves, controllers; feed and reflux line
